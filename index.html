    Elementarium

    Every grain here is simulated: heat spreads, liquids settle by weight, fire looks for fuel, current runs through metal. You start with 26 elements, seven of them seeds. The rest of the table is waiting to be found.

    • Drag paint the selected element · Right-drag erase
    • Scroll zoom · Middle-drag or WASD move the map
    • Ctrl + Scroll or [ ] brush size · 1–7 brush shape · G magnet
    • Ctrl + Z undo · Ctrl + Shift + Z redo
    • Middle-click pick up the element under the cursor
    • Periodic table tab: it starts with hydrogen and helium; unlock the rest one by one in the Lab by identifying mystery samples
    • Weapons tab: click the map to set off a tsunami, earthquake, tornado, hydrogen bomb and more · the brush size sets how big, an earthquake's magnitude sets its strength
    • Space pause · T thermal view · V air view · L magnifying lens · M sound
